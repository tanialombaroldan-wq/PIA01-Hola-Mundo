# PIA01 - Hola Mundo

## Descripción de la tarea

En esta primera práctica del módulo de Programación de Inteligencia Artificial voy a trabajar con GitHub y el lenguaje de programación Python.

El objetivo es aprender a crear un repositorio, añadir un archivo README y realizar un programa sencillo que muestre el mensaje "Hola Mundo".

## Lenguaje utilizado

He utilizado Python porque es un lenguaje fácil de aprender y uno de los más utilizados en el ámbito de la inteligencia artificial.
